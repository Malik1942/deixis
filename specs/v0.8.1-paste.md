# v0.8.1: Return pastes into the agent you used last (opt-in)

**Status:** built Sep 17, 2026; sending removed Sep 19, after the first dogfood. Off by default.
Dogfood before it becomes the default or the README mentions it. Ships in 0.8.1 with
`specs/v0.8.1.md` (trackpad taps and sounds, R59–R62); first written as v0.9 R59, renumbered Sep 19.

## R63 Paste into the agent after Return

Today Return writes the files and the clipboard and stops. The user then switches to the agent and
pastes, or types a sentence so the agent fetches the capture over MCP; either way three steps
remain, and the MCP route removes only the paste. With this option on, Return also brings forward
the agent app the user used last and pastes the capture into its message field, and stops there:
Locant never presses Return in the agent. MCP is not on this path: the clipboard already holds the
payload, and the payload was built to be pasted (the image path is its first line for that reason).
The MCP server is unchanged; it stays the way an agent looks back: history, the image, resolve.

Agent apps, by exact bundle id, never by name (verified on this Mac, Sep 17, 2026; all three Electron):

- Claude: `com.anthropic.claudefordesktop`, /Applications/Claude.app
- Cursor: `com.todesktop.230313mzl4w4u92`, /Applications/Cursor.app
- Codex: `com.openai.codex`, installed as /Applications/ChatGPT.app and shown everywhere as "ChatGPT"

Not agents: `com.openai.chat` (ChatGPT Classic), `com.steipete.codexbar` (CodexBar),
`com.anthropic.claude-code` and `com.anthropic.claude-code-url-handler` (background-only copies inside
the Claude app), and every `*.helper*` id. CLI agents running in a terminal are out of scope.

- **The last agent.** `AppState` records the most recently activated agent app as an
  `NSRunningApplication`, from a `didActivateApplicationNotification` observer of its own, installed
  in `start()` beside `watchAppsForIterations()`. Not inside `appCameForward`: its guards drop events
  while iterations are off or a capture is running. Not persisted; empty after launch until an agent
  app comes forward, and treated as empty once that app terminates. The overlay is a non-activating
  panel, so capturing never overwrites it.
- **When.** Point captures only, sets and drawn frames included: the step runs at the end of
  `commit(note:)`, after the files, the clipboard, `reset()`, and the toast, so a failed capture still
  touches nothing. Snap, Text, Color, and Cut are unchanged.
- **Paste.** Only when the option is on, a last agent exists, and `CGPreflightPostEventAccess()`
  holds. Posting rides on the Accessibility grant Locant already requires; no new permission.
  1. Wait, bounded, until the physical Return and every modifier are up, so a held key cannot leak
     into the posted events.
  2. Activate the agent, then poll `frontmostApplication` every 25 ms for up to 1 s. A notification
     wait would hang when the agent is already frontmost. If it is not frontmost after 300 ms, set
     `kAXFrontmostAttribute` and `AXRaise` its main window through `AccessibilityReader`: `activate()`
     was seen to fail for a window on another Space. On timeout, post nothing.
  3. Wait 150 ms (the overlay orders out about 140 ms after `reset()`), confirm the agent is still
     frontmost, and post ⌘V at `.cgSessionEventTap`: V key down and up with `.maskCommand` set on
     the events themselves. Never separate Command events; they would feed the double-tap detector.
     The V key code comes from the current keyboard layout through `UCKeyTranslate`, not a fixed
     `kVK_ANSI_V`, so Dvorak and an active Chinese input source both paste.
- **Never sends.** Sending stays the user's. The paste waits in the agent's message field, where
  it can be read, edited, trimmed, or deleted before a token is spent. A send cannot be taken back,
  and it goes to whichever chat was used last: in dogfood on Sep 19 an automatic send landed in a
  live chat and interrupted it. If the last Return proves to be friction, a per-capture ⌘↩ in the
  note field (paste and send this one) may come later. Never a Settings switch, and never an undo
  countdown: Esc interrupts the agents.
- **A newer action wins.** Before the agent is brought forward, while waiting for it, and before
  ⌘V, the paste checks that no capture has started and that the clipboard still holds what Return
  wrote (its `changeCount`). If either changed, it stops without a toast: the user has moved on. Two
  quick Returns can overlap, so a count of pastes in flight, not a flag, keeps auto-verify away.
- **Own events.** Every posted event carries a marker in `eventSourceUserData`. `KeyEventTap` passes
  marked events through before the hotkey handler sees them, so a user who recorded ⌘V as a Locant
  hotkey cannot swallow Locant's own paste.
- **Auto-verify.** Activating the agent fires the iteration observer. `appCameForward` ignores
  activations while a paste is in flight, so pointing at an agent's own UI never records the pasted
  text as an after-image.
- **Clipboard.** Unchanged. ⌘V pastes the same one item, Markdown and PNG, that Return writes today.
  Nothing is saved or restored.
- **Feedback.** On success the paste itself is the feedback; the `Copied` toast is unchanged. When
  nothing is pasted the toast says why: `Copied · no agent yet`, `Copied · Cursor didn't come forward`.
- **The hint.** `showAgentHintIfNeeded()` does not run while the option is on, so dogfooding does not
  spend its one showing.
- **Label.** While the option is on, a click-through `HudLabel` sits on the far side of the note field
  from the element, left-aligned with it: `→ Cursor · <window title>`. The app name is the running
  app's `localizedName`, so Codex reads "ChatGPT", as the user sees it. The title comes from
  `AccessibilityReader.focusedWindowTitle(pid:)` on a reader of its own with an AX messaging timeout,
  so a slow agent cannot stall hover on the shared reader; the label shows the name at once and gains
  the title when it arrives. The raw title is shown, truncated. No workspace name is parsed out of it
  until real titles from each app have been sampled. With no last agent the label reads
  `→ no agent yet`. The label reflects the moment the field opened.
- **Settings › Agents**, a new first section, since paste is now the handoff and MCP the optional
  extra. `AgentSettings` gains the `AppState` environment for the bindings.
  - `Paste into your agent`: "After Return, Locant brings forward the agent app you used last,
    Claude, Cursor, or Codex, and pastes the capture into its message field. Locant never sends it;
    you do." Off by default.
  - Footnote: "The note field shows where the capture will go. The clipboard holds it either way, and
    connected agents can still fetch it."
- **Preferences.** `pastesIntoAgent`, default false, in the same pattern as `checksForUpdates`.
- **Layout.** One new file, `Locant/Payload/AgentPaste.swift`: `AgentPaste`, pure (the bundle ids,
  `isAgent(bundleId:)`, `label(appName:windowTitle:)`), and `AgentPaster`,
  which activates and posts. The existing `Agent` enum stays about MCP configuration; the paste
  target is a different product (the Claude app, not the Claude Code CLI).
- **Out of scope.** CLI agents in terminals; persisting the last agent; parsing a workspace name from
  window titles; the in-field hint `↩ copy · esc cancel` and the Help page, which change when the
  option becomes the default; any MCP change.
- **Tests.** `AgentPasteTests`: `isAgent` is true for the three ids and false for every excluded id;
  `label` with and without a title and with a long one. `KeyEventTap`'s marker check as a pure
  predicate. `PreferencesTests`: the default false, and a round trip. Activation and posting are not
  unit tested; they are what dogfood checks.

### Dogfood checks (only a run answers these)

1. What each app takes from the one item carrying both PNG and Markdown: the text, an image
   attachment, or both. If an app takes only the image, the payload text is lost; the fallback for
   that app is to paste a text-only item, then write the full item back. Claude, Sep 19: both, the
   Markdown in the message and the PNG as an attachment.
2. Cursor is an IDE. ⌘V lands wherever focus is, possibly the code editor. Watch how often.
3. Whether activation from Locant, which is never the active app during a capture, is honored on this
   macOS, across Spaces and in full screen.
4. Whether moving focus to the agent on every Return fits the normal workflow.
5. Raw window titles from Claude, Cursor, and ChatGPT, sampled for a later workspace parser.
